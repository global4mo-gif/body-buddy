# Body Buddy — трекер БАДов

Мобильное веб-приложение для трекинга добавок по мотивам дизайна
[Body Buddy в Google Stitch](https://stitch.withgoogle.com/projects/4366326960970563250)
(дизайн-система «Nurture & Logic»).

## Что умеет

- **Онбординг** — профиль: имя, пол, возраст, главный фокус, цель по воде.
- **Сегодня** — кольцо прогресса приёмов, чек-лист добавок по слотам
  (утро / день / вечер), трекер воды, стрик, «мягкий совет» дня.
- **Стек** — добавление добавок из каталога (включая грибные MYKORA:
  Летипорус, Ежовик, Кордицепс, Рейши) или своих; пауза, редактирование,
  удаление; **движок взаимодействий** (синергии и конфликты: железо+C,
  железо vs магний, D3+K2 и др.); адгеренс за 30 дней; точное расписание.
- **Прогресс** — календарь-хитмэп за 4 недели, адгеренс по каждой добавке
  за 14 дней, среднее по воде, цель профиля.
- **База** — «Дешифратор тяги» (тяга к еде → возможный дефицит) и разборы
  нутриентов с признаками дефицита и источниками.

Данные хранятся локально в браузере (localStorage) — без сервера и регистрации.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # продакшен-сборка в dist/
```

Готовую папку `dist/` можно выложить на любой статический хостинг
(Vercel, Netlify, GitHub Pages). На телефоне через «Добавить на экран
"Домой"» работает как приложение.

## Структура

```
src/
  data.js              каталог добавок, правила взаимодействий, база знаний
  store.js             состояние + localStorage, адгеренс, стрик
  styles.css           дизайн-токены Nurture & Logic
  screens/
    Onboarding.jsx     профиль и цели
    Today.jsx          главный экран дня
    Stack.jsx          стек + движок взаимодействий
    AddSupplement.jsx  каталог и форма добавления
    Progress.jsx       хитмэп и статистика
    Knowledge.jsx      дешифратор тяги и нутриенты
```
